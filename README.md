# TECHFEST 2026 — Ignite the Future

A responsive, single-page landing-page concept inspired by the science, technology, creativity and innovation spirit of Techfest, IIT Bombay.

## Features
- Responsive mobile and desktop layout
- Pure HTML, CSS and vanilla JavaScript
- Animated abstract CSS visual (no 3D assets or external libraries)
- Scroll reveal, mobile navigation, event/theme cards
- Links to the official Techfest website

## Run locally
Open `index.html` in any modern browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `techfest-ignite-landing-page`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Demo video
Record a short screen video showing the hero section, scrolling through all sections, the mobile layout if possible, and clicking the official website link. Upload the video to Google Drive and set General access to **Anyone with the link — Viewer**.
